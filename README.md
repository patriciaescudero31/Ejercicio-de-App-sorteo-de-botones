# Ejercicio: App Sorteo de Botones ("Elige tu destino")

Aplicación interactiva y ligera construida con **HTML5**, **CSS3** y **JavaScript**.

## 🎮 Características
- **Título principal**: *"Elige tu destino"*.
- **Dos botones interactivos**: Botón Rojo 🔴 y Botón Azul 🔵 con animaciones y efectos hover.
- **Resultado aleatorio**: Al pulsar cualquiera de los botones, se determina al azar si *"¡Has ganado!"* o *"Has perdido"*.
- **Botón "Volver a jugar"**: Permite reiniciar la partida y volver a probar suerte.
- **Diseño limpio y moderno**: Interfaz centrada, adaptable a dispositivos móviles (responsive), con estética moderna y contador de victorias/derrotas.

## 🚀 Cómo abrir el proyecto
Puedes abrir el archivo [`index.html`](./index.html) directamente con doble clic en tu navegador web favorito (Chrome, Safari, Firefox, Edge, etc.) o utilizar una extensión como *Live Server*.
